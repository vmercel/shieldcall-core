# Endeavor Plan (years 1–3)

Condensed from the 2026-08-22 upgrade checklist. The petitioner is integral
because the unique combination — telephony DSP + discourse trajectory +
sequential decision under interruption cost + fail-open sidecar doctrine —
is already formulated, negatively tested, and owned here. A random ML
engineer could replace a residual scorer; they could not replace that
combination without repeating the program.

## Kill / pivot (written in advance)

- If a hybrid encoder never beats residual-at-chance on **any**
  neural-telephony condition, drop “acoustic detector” as a contribution;
  freeze a public anti-spoofing encoder as the sensor.
- If a trajectory model never beats a **wide** locked lexicon on independent
  text, drop “discourse novelty.” **This kill already fired:** on the
  independent set, SDTG AUC 0.82 vs wide-lexicon 0.84. Wide lexicon stays
  as the linguistic sensor; HMM path is a baseline, not a claim.
- If gold SAPC is negative with power, keep it as a public protocol.
- If no independent letter and no peer-reviewed accept by month 12, **do
  not file NIW** on this endeavor yet.

## Budget (order of magnitude, not a startup fantasy)

Compute: public-cloud CPU/GPU credits for ASVspoof-scale eval (single-digit
thousands USD/year at research intensity). Data: ASVspoof 5 license when
granted; Mini LibriSpeech already local. No TAM. Precision at a declared
alert budget is the operating metric of any trial.
